# Mealler (QuranEnc.com)

Bu klasördeki `<anahtar>.json` dosyaları `python scripts/fetch_quranenc.py` ile üretilir.
Elle düzenlenmez: QuranEnc şartları gereği çeviri metni değiştirilemez.

Dosyalar yoksa sunucu açılır ama meal alanları boş döner; web istemcisi meali doğrudan
QuranEnc'ten aldığı için çalışmaya devam eder.
